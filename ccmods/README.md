My Cookie Clicker mods
===

[Better Wrinkler Info](./betterWrinklerInfo.js)
---

A simple mod that adds some extra info to the stats screen and wrinkler messages for shiny hunters. Requires CCSE.

- New stats
  - Shiny wrinkler count (all time)
  - Total wrinkler count (all time)
  - Wrinklers popped since last shiny wrinkler
  - Longest shiny wrinkler drought
- Other features
  - "Wrinkler exploded" popup now includes running total of wrinklers since your last shiny (toggleable in settings)
  - Shiny wrinkler popup also shows this count, lingers for much longer, and actually uses the shiny wrinkler icon (not sure why the vanilla game doesn't do that tbh)
  - Stats automatically resync if you pop any wrinklers without the mod loaded (assumes you did not pop any shiny wrinklers)
